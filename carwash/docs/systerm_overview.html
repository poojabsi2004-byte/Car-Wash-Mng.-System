1. Security Groups

All five groups share one res.groups.privilege ("Car Wash", defined in carwash_base). A user's visible menus, buttons, and record access are all driven by group membership — there is no per-user configuration beyond this.

GroupXML IDImplies (inherits access from)
Front Deskcarwash_base.group_carwash_userInternal User
Managercarwash_base.group_carwash_managerFront Desk
Washer/Detailercarwash_jobcard.group_carwash_washerInternal User
QC Inspectorcarwash_jobcard.group_carwash_qcInternal User
Ownercarwash_multibranch.group_carwash_ownerManager, Multi Companies

"Implies" means membership in that group automatically grants everything the implied group grants too — e.g. every Manager automatically has full Front Desk access, and every Owner automatically has full Manager (and therefore Front Desk) access. Washer and QC are independent branches; neither implies nor is implied by the others.
